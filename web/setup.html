GHOSTLAB

Server setup helper

Fill this in and it writes everything for your free Oracle Cloud server: the script to paste in, your admin code, and every driver's link and code. It all stays in this browser; nothing is sent anywhere.

1Your DuckDNS name

Get these free at duckdns.org: add a subdomain, then copy the token shown at the top of the page.

2Drivers

One name per line. Each gets their own UDP port and access code. You can add or remove people later from the website.

3Your GitHub

Leave blank and everyone's links open the app straight from your server instead. That works just as well, and doesn't need GitHub Pages at all.

Your admin link (keep it to yourself)

Sees every driver, live and saved laps, and lets you add or remove drivers. Open it once on your phone and add it to your home screen.
